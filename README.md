# hypr-game-mode

TUI command center for Hyprland — Android control, game launcher, and performance tuning.

## Install

```bash
yay -S hypr-game-mode
```

## Features

- **Android/Scrcpy** — Mirror, wireless connect, screen record, low-res mode
- **Game Launcher** — Auto-discover games, optional MangoHud overlay, auto performance mode
- **Performance Mode** — Toggle animations/blur/shadows, gamemoded integration
- **Settings** — Configure gamemoded via menu

## Dependencies

`bash` `gum` `scrcpy` `android-tools` `libnotify` `mangohud` `gamemode`

## Config

`~/.config/hypr-game-mode/config` — created on first run.
